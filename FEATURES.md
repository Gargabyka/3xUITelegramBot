# VPN Telegram Bot — документация

## Обзор

Бот раздаёт и обслуживает VPN-подключения (VLESS + Reality через 3x-ui) через Telegram: пользователь сам создаёт себе подключение, получает QR-код и ссылку `vless://`, видит свой трафик; администратор управляет пользователями, лимитами и привязкой подключений.

- **VPN-сервер:** [3x-ui](https://github.com/MHSanaei/3x-ui) v3 (Xray, inbound VLESS + Reality). Бот работает через его HTTP API (`/panel/api/clients/*`, авторизация Bearer-токеном) — создание, удаление, включение/отключение клиентов, выдача ссылок и счётчиков трафика. Соединение пользователя = клиент в заданном inbound, имя соединения = email клиента.
- **Хранилище:** SQLite (EF Core). Хранит пользователей бота, локальную копию peer'ов, связи «пользователь ↔ peer», снимки трафика и состояние напоминаний.
- **Telegram:** long polling, навигация через inline-кнопки. Команды: `/start` (главное меню) и `/status` (статус системы, только для админов).
- **Стек:** .NET, слои Domain / Application / EFCore / XUi / Telegram / Host; разворачивается в Docker рядом с 3x-ui.

## Роли и доступ

Бот закрытый: на любое сообщение или нажатие кнопки от незарегистрированного человека он отвечает «Доступ запрещён». Самостоятельной регистрации нет — пользователей добавляет администратор.

| Роль | Как получить | Что доступно |
| --- | --- | --- |
| Суперадмин | Telegram ID в настройке `Telegram:AdminIds` | Всё. Роль нельзя изменить из бота, пользователя нельзя удалить |
| Администратор | Роль выдана другим админом в карточке пользователя | Админ-панель, `/status`, все соединения сервера |
| Пользователь | Добавлен админом по контакту | Только свои соединения, в пределах лимита |

При каждом обращении бот обновляет имя, фамилию и @username пользователя из Telegram.

## Возможности пользователя

Главное меню (`/start`) даёт две кнопки: «Список соединений» и «Добавить соединение»; у админов есть третья — «Админ панель».

### Мои соединения

- Список привязанных к аккаунту peer'ов с постраничной навигацией; зелёная/красная метка — включён или отключён.
- Внизу списка — суммарный трафик по всем соединениям.

### Карточка соединения

- QR-код со ссылкой `vless://` для импорта в клиент (v2rayNG, Hiddify, Streisand и т.п.).
- Информация: имя, адрес, включён ли клиент, последнее рукопожатие (или «ещё не подключался»).
- Трафик за сутки, 7 дней, 30 дней и за всё время.
- Кнопки: «Скачать ссылку / конфиг», «📖 Инструкция» (как подключить именно этот профиль: приложения и шаги импорта), «✏ Переименовать», «Отключить / Включить», «Удалить клиента» (с подтверждением), «Назад».
- «✏ Переименовать» меняет имя соединения на сервере (те же правила, что при создании, имя должно быть свободно). Ключи не меняются, подключение продолжает работать без повторного импорта.
- Чужое соединение обычный пользователь не может открыть, скачать, включить/отключить или удалить — права проверяются при каждом нажатии, поэтому кнопки в старых сообщениях после отвязки соединения или снятия роли админа перестают работать.

### Добавление соединения

1. Нажать «Добавить соединение». Если лимит исчерпан, бот покажет «Достигнут лимит соединений: N/M» и предложит обратиться к администратору.
2. Если настроено несколько профилей (VLESS Raw / XHTTP / XHTTP CDN, AmneziaWG), бот предложит выбрать один и коротко опишет, чем они отличаются; при одном профиле шаг пропускается.
3. Ввести имя соединения — от 3 до 32 символов (латиница, цифры, `_`, `.`, `-`), имя должно быть уникальным на сервере выбранного протокола. Можно нажать «Отмена»; если имя не ввести за 15 минут, сценарий сбрасывается.
4. Бот создаёт клиента на сервере выбранного протокола (3x-ui или amnezia-wg-easy), сохраняет его в БД и привязывает к аккаунту, затем предлагает перейти к списку соединений.

## Возможности администратора

Администратору доступно всё то же, что пользователю, плюс админ-панель и команда `/status`.

### Админ-панель

| Кнопка | Что делает |
| --- | --- |
| Список клиентов | Все клиенты inbound'а с пагинацией; по нажатию — карточка с QR, трафиком, скачиванием, включением/отключением и удалением |
| Добавить пользователя | Админ отправляет контакт кнопкой «Отправить контакт»; бот создаёт пользователя с ролью «Пользователь» и лимитом по умолчанию |
| Пригласить по ссылке | Бот создаёт одноразовую ссылку `t.me/бот?start=inv_…`; перешедший по ней незнакомый человек получает роль «Пользователь» и лимит по умолчанию, а создавший ссылку админ получает уведомление. Ссылка действует `Telegram:InviteLifetimeDays` дней |
| Список пользователей | Все пользователи бота; по нажатию — карточка пользователя |
| Обновить соединения | Синхронизирует БД с серверами: добавляет клиентов, созданных мимо бота, обновляет имя и статус, удаляет записи о клиентах, которых больше нет на сервере (только если сервер ответил и вернул непустой список); отчёт: всего / добавлено / обновлено / удалено |
| 📊 Статистика | Кто сейчас онлайн (активность за последние 3 минуты) и топ-10 соединений по трафику за 30 дней с владельцами; кнопка «Обновить» |
| 📣 Рассылка | Админ отправляет любое сообщение (текст, фото, файл — с форматированием), бот просит подтверждение и копирует его всем пользователям бота; в конце — отчёт: доставлено / не доставлено |
| 📜 Журнал действий | Кто, что и когда менял: создание, удаление, включение/отключение и переименование соединений, действия с пользователями, приглашения, синхронизация, рассылки. Новые записи первыми, по 10 на страницу |

### Карточка пользователя

Показывает данные профиля, роль, лимит соединений и статус напоминаний.

- **Посмотреть соединения** — список его peer'ов, суммарный трафик, кнопка «Разорвать» (отвязать peer от пользователя без удаления с сервера).
- **Добавить соединение** — привязать существующий свободный peer; уже привязанные к другим не показываются.
- **Изменить роль** — «Администратор» или «Пользователь».
- **Изменить лимит соединений** — число или «Без лимита». Лимит ограничивает только самостоятельное создание; админ может привязать больше.
- **Включить / отключить напоминания** об оплате для этого пользователя.
- **Удалить пользователя** — с подтверждением, необратимо.

Пользователей из `AdminIds` нельзя удалить и нельзя сменить им роль.

### Команда /status

Возвращает сводку: доступен ли API 3x-ui, сколько peer'ов всего / включено / отключено, число пользователей бота и дату следующего напоминания об оплате.

## Фоновые процессы

Фоновые сервисы: снимки трафика и синхронизация соединений (раз в час), напоминания об оплате и мониторинг серверов. Кроме снимков трафика, раз в час выполняется та же синхронизация соединений, что и по кнопке «Обновить соединения».

### Снимки трафика

- Раз в час бот сохраняет счётчики RX/TX каждого клиента из 3x-ui.
- Живые счётчики сбрасываются при перезапуске интерфейса, поэтому статистика за сутки / 7 / 30 дней и за всё время считается по снимкам с учётом сбросов.
- Пока снимков нет, в карточке пишется «сбор начнётся в течение часа».
- Раз в сутки снимки старше 35 дней сжимаются: удаляются промежуточные снимки без сброса счётчиков, поэтому итог «за всё время» не меняется, а база не растёт бесконечно.

### Напоминания об оплате хостинга

- Включаются настройкой `HostingReminder:Enabled`.
- Дата очередного напоминания = `LastPaymentDate` + N × `PeriodMonths` (по умолчанию каждые 2 месяца). Дата всегда считается от исходной, поэтому не «плывёт» для дат конца месяца.
- В день срока текст из `HostingReminder:Message` уходит всем пользователям бота, кроме тех, кому админ отключил напоминания.
- Если бот был выключен несколько циклов, уходит одно напоминание, а не по одному за каждый пропущенный цикл.

### Мониторинг серверов

- Каждые `Monitoring:IntervalMinutes` минут бот опрашивает все VPN-серверы.
- Если сервер не ответил `Monitoring:FailureThreshold` проверок подряд, все администраторы (суперадмины и пользователи с ролью «Администратор») получают сообщение с причиной.
- Когда сервер снова отвечает, приходит сообщение о восстановлении с длительностью простоя.

## Настройка и развёртывание

Бот запускается через `docker-compose.yml` на том же сервере, что и 3x-ui; настройки задаются в `appsettings.json` или переменными окружения (`Раздел__Ключ`).

Секреты (`TELEGRAM_TOKEN`, `TELEGRAM_ADMIN_ID`, `XUI_API_URL`, `XUI_API_TOKEN`, `AMNEZIA_PASSWORD` и др.) в `docker-compose.yml` не хранятся — там только ссылки `${...}`. В Portainer значения задаются один раз в Stack → Environment variables (Advanced mode — можно вставить содержимое `.env.example`) и сохраняются между redeploy. Локально они берутся из файла `.env` рядом с compose (в git не попадает, образец — `.env.example`). Без обязательных переменных стек не развернётся и покажет, какой не хватает.

| Ключ | Назначение | По умолчанию |
| --- | --- | --- |
| `Telegram:Token` | Токен бота от @BotFather | — |
| `Telegram:AdminIds` | Telegram ID суперадминов (массив) | — |
| `Telegram:DefaultConnectionLimit` | Лимит соединений для новых пользователей; пусто = без ограничений | 3 |
| `Telegram:InviteLifetimeDays` | Сколько дней действует ссылка-приглашение | 7 |
| `XUi:ApiUrl` | Адрес панели 3x-ui вместе с webBasePath | — |
| `XUi:ApiToken` | API-токен (Settings → Security → API Token) | — |
| `XUi:Inbounds` | Профили VLESS — массив из inbound'ов панели (при выборе соединения каждый показывается отдельной кнопкой) | — |
| `XUi:Inbounds:N:Id` | ID inbound'а (колонка ID в панели) | — |
| `XUi:Inbounds:N:Profile` | Профиль inbound'а: `VlessRaw`, `VlessXhttp` или `VlessXhttpCdn` (каждый не более одного раза) | — |
| `XUi:Inbounds:N:Port` | Порт, который подставляется в ссылку и QR вместо порта inbound'а (например, 443 за CDN) | порт inbound'а |
| `XUi:Inbounds:N:Flow` | XTLS flow профиля; пустая строка — без flow (нужно для XHTTP) | `XUi:Flow` |
| `XUi:Flow` | XTLS flow новых клиентов | `xtls-rprx-vision` |
| `XUi:AllowInvalidCertificate` | Игнорировать ошибки TLS панели (самоподписанный сертификат) | `false` |
| `AmneziaWg:Enabled` | Включить подключения через [amnezia-wg-easy](https://github.com/w0rng/amnezia-wg-easy) | `false` |
| `AmneziaWg:ApiUrl` | Адрес веб-интерфейса amnezia-wg-easy | — |
| `AmneziaWg:ApiPassword` | Пароль веб-интерфейса (`PASSWORD` контейнера) | — |

Соединение AmneziaWG выдаётся файлом `amnezia.conf` (импорт в приложение AmneziaWG/AmneziaVPN); в списках и карточках у соединений есть метка протокола (`[VLESS]`, `[AWG]`).
| `ConnectionStrings:Sqlite` | Строка подключения SQLite | `Data Source=vpn_bot.db` (в Docker — `/data/vpn_bot.db`) |
| `HostingReminder:Enabled` | Включить напоминания об оплате | `false` |
| `HostingReminder:LastPaymentDate` | Дата последней оплаты, точка отсчёта | — |
| `HostingReminder:PeriodMonths` | Период оплаты, месяцев | 2 |
| `HostingReminder:Message` | Текст напоминания с реквизитами | — |
| `Monitoring:Enabled` | Проверять доступность VPN-серверов и уведомлять админов | `true` |
| `Monitoring:IntervalMinutes` | Как часто проверять серверы, минут | 5 |
| `Monitoring:FailureThreshold` | Сколько проверок подряд сервер должен не отвечать, чтобы прислать уведомление | 2 |

База хранится в томе `./data`. После первого запуска существующие peer'ы подтянутся фоновой синхронизацией в течение часа (или сразу — кнопкой «Обновить соединения»); затем их нужно привязать к пользователям.
